Models and libraries

Nothing in the product runs a machine-learning model today. Every signal on screen — the near-duplicate groups, the sharpness reading, the best shot, the burst grouping — is arithmetic over measurements the browser takes at upload. That is the baseline this table protects: a model earns a row only when a deterministic method cannot do the job.

Why one row is blocked

InsightFace ships its code under MIT, but the pretrained buffalo_* packs are released for non-commercial research only. Phase 12 face grouping cannot be built on them and also charge for the product. Nothing has been installed — this was found while writing the registry, which is the reason the registry exists.

Where a model is allowed to run

Three zones, and one boundary that matters: the moment a photograph leaves the owner's device. Which zone a model sits in decides what it costs, what it can see, and whether it needs a key.

How an album moves

A-02 Album lifecycle · product states, not a database enum 
stateDiagram-v2
    [*] --> SignedOut
    SignedOut --> Library: sign in
    Library --> AlbumDraft: create album
    AlbumDraft --> Uploading: add photos
    Uploading --> Editing: upload completes
    Uploading --> Uploading: retry failed files

    Editing --> Curating: review near-duplicates
    Curating --> Editing: keep, or remove after confirmation

    Editing --> StudioDraft: request AI assistance
    StudioDraft --> Editing: revise or reject
    StudioDraft --> Editing: accept into editable content

    Editing --> Private: save privately
    Private --> LinkShared: create share link
    Private --> Public: publish publicly
    LinkShared --> Private: rotate or revoke link
    Public --> Private: unpublish

    Editing --> DeletionPending: request deletion
    Private --> DeletionPending: request deletion
    LinkShared --> DeletionPending: request deletion
    Public --> DeletionPending: request deletion
    DeletionPending --> Editing: cancel
    DeletionPending --> [*]: confirm deletion

    Library --> SignedOut: sign out

Only visibility and durable content are persisted. StudioDraft is drawn because the invariant lives there: AI output enters as a draft and reaches an album only after the owner accepts it.

Keeping this drawing true

A map that lags the code is worse than none, because it is trusted. Two rules, both now in AGENTS.md:

  • A pull request that changes a boundary, a route, a table, or the model registry updates docs/project-structure.md in the same pull request.
  • A pull request that adopts, replaces, or rules out a model or library lands its row here — licence included — before the dependency lands. A model that reaches the repository before it reaches this table is how a non-commercial licence gets adopted by accident.
